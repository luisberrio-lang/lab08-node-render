# Laboratorio 08 — Despliegue de aplicaciones Node.js

Este repositorio contiene los dos entregables solicitados:

- `despliegue01`: servidor HTTP de Node.js con dotenv, Yarn, Nodemon y puerto dinámico.
- `proyecto-anterior`: portafolio responsive de Luis Washington Berrio Valencia, creado como proyecto nuevo a partir del CV real disponible y servido con Express.

## Pruebas locales

```bash
cd despliegue01
yarn install
yarn test
yarn dev
```

```bash
cd proyecto-anterior
yarn install
yarn test
yarn dev
```

## Render

El archivo `render.yaml` declara dos Web Services gratuitos, cada uno con su directorio raíz, comando de instalación y comando de inicio. No se encontró el proyecto web de CV de semana 2; por ello, el portafolio se documenta expresamente como una creación nueva.
