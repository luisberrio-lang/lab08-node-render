# Laboratorio 08 — Despliegue de aplicaciones Node.js

Este repositorio contiene los dos entregables solicitados:

- `despliegue01`: servidor HTTP de Node.js con dotenv, Yarn, Nodemon y puerto dinámico.
- `proyecto-anterior`: proyecto Express + EJS de una semana anterior, conservando sus rutas y vistas y adaptado para producción.

## Pruebas locales

```bash
cd despliegue01
yarn install
yarn test
yarn dev
```

```bash
cd proyecto-anterior
yarn install
yarn test
yarn dev
```

## Render

El archivo `render.yaml` declara dos Web Services gratuitos, cada uno con su directorio raíz, comando de instalación y comando de inicio.
